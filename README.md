# My Portfolio Website

A personal portfolio website built with HTML, CSS, and JavaScript.

## Live Demo

[Live Demo](https://waleedabdi.github.io/Team-Project/)

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Navigation bar
- Personal introduction
- Projects section
- Testimonials section
- Contact section
- Responsive design

## How to Run Locally

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser, or serve the folder with a local static server.

## What I Learned

I learned how to structure a webpage with HTML, style it with CSS, and add responsive and interactive behavior with JavaScript.
